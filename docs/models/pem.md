# Pem

Reference to the stored RSA private key used for Snowflake authentication. Required for both <code>oauth</code> and <code>keypair</code> authentication.


## Fields

| Field                                                                                                   | Type                                                                                                    | Required                                                                                                | Description                                                                                             | Example                                                                                                 |
| ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `key_name`                                                                                              | *str*                                                                                                   | :heavy_check_mark:                                                                                      | Name of the stored private key, as listed by <code>/lib/private-keys</code>, to authenticate with.      | snowflake-keypair                                                                                       |
| `passphrase`                                                                                            | *Optional[str]*                                                                                         | :heavy_minus_sign:                                                                                      | Server-resolved passphrase for the stored private key. Ignored on input and omitted from responses.     |                                                                                                         |
| `priv_key_path`                                                                                         | *Optional[str]*                                                                                         | :heavy_minus_sign:                                                                                      | Server-resolved filesystem path to the stored private key. Ignored on input and omitted from responses. |                                                                                                         |
