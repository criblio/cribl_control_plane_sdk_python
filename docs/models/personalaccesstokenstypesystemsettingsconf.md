# PersonalAccessTokensTypeSystemSettingsConf

Leader policy for Personal Access Tokens (PATs). When this section is omitted, PATs are disabled.


## Fields

| Field                                                                                                                                                                                                                                              | Type                                                                                                                                                                                                                                               | Required                                                                                                                                                                                                                                           | Description                                                                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `enabled`                                                                                                                                                                                                                                          | *Optional[bool]*                                                                                                                                                                                                                                   | :heavy_minus_sign:                                                                                                                                                                                                                                 | If <code>true</code>, users can create and authenticate with PATs. Otherwise, <code>false</code> (default). Takes effect when saved, without a restart.                                                                                            |
| `max_ttl`                                                                                                                                                                                                                                          | *Optional[int]*                                                                                                                                                                                                                                    | :heavy_minus_sign:                                                                                                                                                                                                                                 | Maximum lifetime, in seconds, a user can request for a new PAT. Requests for a longer lifetime are rejected. Minimum is <code>1</code>; maximum and default is <code>31536000</code> (1 year). Lowering this value does not shorten existing PATs. |
